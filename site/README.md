# Саманта: Коды к мужчинам

Снимок текущей тестовой версии лендинга Вики Хотян. Текст и дизайн перенесены без изменений; перерисовка отложена до сбора отзывов.

Просмотр текущего сайта: https://samanta-kody-k-muzhchinam-vika.koalspb.chatgpt.site — доступ ограничен владельцем, публикация исходников не меняет доступ к сайту.

В этой папке находятся HTML, стили, JavaScript, иллюстрации и лицензии шрифтов. Для локального просмотра достаточно обычного статического HTTP-сервера. Сам файл видео не хранится в GitHub; в HTML указан его адрес на текущем закрытом сайте, поэтому видео требует соответствующего доступа.

Превью автора: [vika-video-preview.webp](../assets/brand/vika-video-preview.webp).

## Использование из другого чата

Передай чату ссылку на этот репозиторий и явно попроси прочитать нужные файлы через подключённый GitHub. Для превью можно передать прямую ссылку:

https://raw.githubusercontent.com/vikakhotian/types/main/assets/brand/vika-video-preview.webp

Пример запроса: «Открой репозиторий vikakhotian/types. Используй изображение assets/brand/vika-video-preview.webp как референс. Изображения с сайта находятся в site/assets/. Не сглаживай выразительные признаки персонажей».

Если у другого чата нет доступа к GitHub или чтению изображений по ссылкам, скачай нужную картинку из репозитория и приложи её в чат. Файлы из этой беседы не появляются в другом чате автоматически.
