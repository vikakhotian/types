# Саманта: Коды к мужчинам

Текущая тестовая версия лендинга Вики Хотян. В этой редакции переработаны первый экран, меню, кнопки, персонажи и блок автора; добавлены общие настройки навигации и фавикон.

Просмотр текущего сайта: https://samanta-kody-k-muzhchinam-vika.koalspb.chatgpt.site — доступ определяется текущими настройками Sites; публикация исходников сама по себе его не меняет.

В этой папке находятся HTML, стили, JavaScript, иллюстрации и лицензии шрифтов. Для локального просмотра достаточно обычного статического HTTP-сервера. Сам файл видео не хранится в GitHub; в HTML указан его адрес на текущем закрытом сайте, поэтому видео требует соответствующего доступа.

Превью автора: [vika-video-preview.webp](../assets/brand/vika-video-preview.webp).

## Использование из другого чата

Передай чату ссылку на этот репозиторий и явно попроси прочитать нужные файлы через подключённый GitHub. Для превью можно передать прямую ссылку:

https://raw.githubusercontent.com/vikakhotian/types/main/assets/brand/vika-video-preview.webp

Пример запроса: «Открой репозиторий vikakhotian/types. Используй изображение assets/brand/vika-video-preview.webp как референс. Изображения с сайта находятся в site/assets/. Не сглаживай выразительные признаки персонажей».

Если у другого чата нет доступа к GitHub или чтению изображений по ссылкам, скачай нужную картинку из репозитория и приложи её в чат. Файлы из этой беседы не появляются в другом чате автоматически.

Исходные таблицы типажей: [первая](../assets/characters/references/types-reference-01.png), [вторая](../assets/characters/references/types-reference-02.png).

## Общие переходы лендинга и теста

Единственный источник адресов — `site-config.js`:

- `homeUrl`: главный лендинг; все логотипы ведут сюда.
- `contactUrl`: `https://t.me/vikanio`; сюда ведут и «Контакты», и «Запись на первый уровень».
- `testUrl`: `https://samanta-kody-k-muzhchinam-vika.koalspb.chatgpt.site/test/`. Опубликована страница в подготовке; сам тест подключается отдельно.

На странице теста нужно последовательно подключить `site-config.js`, затем `site-navigation.js` с `defer`. Если тест находится в подпапке, использовать корректные относительные пути, например `../site-config.js` и `../site-navigation.js`. Логотипу добавить атрибут `data-site-home`, ссылкам контактов и записи — `data-site-contact`. Кнопке перехода в тест — `data-site-test`. Эти атрибуты не требуют дублировать адреса в коде теста. Чтобы позднее открыть общую форму вместо Telegram, достаточно изменить только `contactUrl`.

Фавикон: `assets/favicon.svg`. Рукописный логотип, главный заголовок и заголовки разделов используют Caveat; отдельные подписи — Neucha.

Карусели карточек и отзывов повторяются по кругу без автоматического перелистывания. По предоставленным фотографиям добавлены рисованные портреты Александры Турсуновой и Александра Андреева. Остальные аватарки пока условные; их можно заменить после получения фотографий.

Страница теста: `test/index.html`. Точка подключения содержимого — `<main id="test-app" data-test-mount>`. Инструкция для следующего чата: [test/README.md](test/README.md).
