# Подключение теста

Страница `/test/` уже размещена. Пока это явно обозначенная страница в подготовке, без вопросов, результатов и сбора данных.

В следующем чате замените содержимое `<main id="test-app" data-test-mount>` в `index.html` на реализацию теста. Сохраните общее меню, favicon и последовательное подключение `../site-config.js`, `../site-navigation.js`. Логотип использует `data-site-home`, контакты и запись — `data-site-contact`; адреса задаются только в `site-config.js`.

`test-shell.js` управляет только мобильным меню. `app.js` лендинга сюда подключать не нужно. Стили страницы наследуют общую систему сайта через CSS в родительской папке. Если тест собирает или передаёт ответы и контакты, отдельно определите получателя, хранение и необходимые тексты о данных; не показывайте фиктивное подтверждение отправки.
