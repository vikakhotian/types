# Типы мужчин

Авторский коммерческий образовательный и исследовательский проект о типологиях, общении и отношениях. Рабочее название проекта — «Типы мужчин»; окончательный бренд ещё не утверждён.

Репозиторий `vikakhotian/types` предназначен для публичной технической документации и будущих разработок проекта. Исходное описание репозитория: «Образовательный проект по Типологиям».

В репозитории находятся документация, исходники текущего сайта с тестом в `site/` и проектные навыки Codex для работы с контентом. Добавление навыков не меняет согласованные тексты, оформление и логику сайта. Навыки описывают рабочие процедуры; они не подключают аккаунты, не запускают фоновую автоматизацию и не публикуют материалы автоматически.

## Проектные навыки

Навыки хранятся в `.agents/skills/` и применяются из рабочей копии этого репозитория. Редактура встроена в CONTENT_STYLE.md и используется во всех текстовых задачах.

- [types-factcheck](.agents/skills/types-factcheck/SKILL.md) — проверка фактов и источников внутри GPT/Codex.
- [types-trendwatch](.agents/skills/types-trendwatch/SKILL.md) — поиск тем по реальным публичным данным и предоставленным выгрузкам.
- [types-reels](.agents/skills/types-reels/SKILL.md) — сценарий, записанный голос автора, субтитры, сборка и проверка ролика.
- [types-client-communication](.agents/skills/types-client-communication/SKILL.md) — сообщения клиенткам и партнёрам с контекстной редактурой.

Это проектные навыки, а не глобальная установка на аккаунт. Если интерфейс не показывает их автоматически, помощник может открыть нужный SKILL.md по прямому запросу. ChatGPT/Work не получает файлы этой рабочей копии автоматически.

## Порядок работы

Вика описывает задачу обычным языком. Codex проверяет доступные материалы, выбирает простой способ реализации, выполняет разрешённую работу, проверяет результат и показывает изменения. Предложения об обновлении постоянных правил согласуются до сохранения. Первоначальное создание этих восьми файлов прямо разрешено заданием; последующие изменения подчиняются [AGENTS.md](AGENTS.md).

Публичный репозиторий не предназначен для закрытых исследований, купленных курсов, клиентских данных и секретов. Передача файла в чат сама по себе не разрешает публикацию. Создание текста или изображения с помощью GPT/Codex не снимает требований конфиденциальности и проверки прав.

Запись файлов в рабочей копии, локальный коммит, отправка в GitHub и публикация сайта — разные действия. Отправка и публикация требуют явного разрешения Вики на конкретный состав материалов. Публикация согласованного набора документации и навыков разрешена Викой 30.10.2026; разрешение на будущие публикации этим не предоставляется.
