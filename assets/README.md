## Для другого чата

Передай ссылки на файлы и попроси открыть изображения через подключённый GitHub. Материалы не становятся автоматически доступны во всех чатах.

Пример: «Открой репозиторий vikakhotian/types и используй обе картинки из assets/characters/references/ как визуальные референсы. Сохраняй выразительные носы, челюсти и другие отличительные признаки. Надписи с картинок не переноси в новый дизайн».
